# Skill: research-summary

## Purpose
Produce a reusable research summary that is easy to compare across runs.

## Output Format
Return Markdown with the exact sections below, in order:

1. Question
- One sentence stating the research question.

2. Key Findings
- 3 to 5 concise findings supported by evidence.

3. Related Links
- Local Paths: relevant project files.
- External Links: authoritative references.

4. Evidence Gaps
- Unknowns, weak evidence, or unverified claims.

5. Next Step
- One concrete action for the next iteration.

## Rules
- Label uncertain statements clearly.
- Do not fabricate citations.
- Keep wording concise and practical.
